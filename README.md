## 🛠️ Architecture & Vibe Coding Philosophy

- **Single-File Vanilla JS:** Each application is built as a self-contained, lightweight web application (`index.html`) using HTML5, CSS3, Tailwind CSS, and Vanilla JavaScript (or Three.js for 3D apps).
- **Zero Node Dependencies:** No `node_modules`, build pipelines, or complex setup required.
- **Pedagogical Design:** Built to empower educators and students with instant visual feedback.
